# Kaladont — ilustracije događaja

12 PNG datoteka, svaka 320 × 320 px, RGBA, transparentna pozadina.

Izrađeno ugrađenim Imagegenom uz prethodne Kaladont ikonice kao stilske reference. Paleta: #1d6f5c, #fdfaf2, #f4c95d, #e4572e, #1a1815, s tonovima za sjene i odsjaje.

Ilustracije nemaju natpise, imena igrača ili broj plasmana. Sve dinamičke informacije dodaju se kroz kod.

`asset-map.json` povezuje semantičke ID-eve i datoteke. `postolja.json` sadrži položaje i veličine avatara na postoljima. `UGRADNJA.md` opisuje konkretna stanja i komponente u pregledanom repozitoriju.

Postolja namjerno imaju velik proziran prostor iznad platformi. Nemoj ih automatski obrezivati ili centrirati prema neprozirnom sadržaju: taj je prostor namijenjen avatarima.
